## What the AI Feed Includes
- Source-to-skill mapping across all listed repos
- Category playbooks (crypto, forensics, web, reverse, JS, maze/state)
- Universal solve workflow
- High-value heuristics and common failure modes
- Prompt template for consistent AI behavior
- Suggested practice progression

## Usage
1. Open `AI_KNOWLEDGE.md`
2. Paste it into your AI system prompt/context
3. Add your current challenge prompt/files
4. Ask for: category classification, top solve hypotheses, and a step-by-step solve plan
